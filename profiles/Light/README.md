# Light Profile

A lightweight QGIS profile with a simplified interface, designed for quick and simple use cases.

## Content

- Custom splash screen and SVG icon
- [New Temporary Layer](https://plugins.qgis.org/plugins/newmemorylayer/) plugin, for quickly creating a temporary layer with `Ctrl+W`
- Several menus and panels have been disabled to keep the interface simple
- Lightweight background map loaded into a project by default
